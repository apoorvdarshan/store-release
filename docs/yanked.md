# Yanked versions

Versions listed here must not be used. Apps pinned to one fail their Store checks;
their release runs print a warning. Read from `main` by `run.py yanked check`. Add an
entry through a normal PR, then ship the fixed patch ([release-process.md](release-process.md#yanking)).
