# store-release

Reusable GitHub Actions workflows and Python tooling that build, sign and publish iOS
and Android apps to App Store Connect and Google Play, pinned by commit SHA.

It starts as [Fud AI](https://github.com/apoorvdarshan/fud-ai)'s release pipeline,
moved into a shared repository with its behaviour kept exactly. The first release,
v0.1.0, is being built; see the [CHANGELOG](CHANGELOG.md).
